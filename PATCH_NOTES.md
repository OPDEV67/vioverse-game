# Vioverse Patch Notes

## v0.7 — Moonlit Companions
- Refined the playable Home screen to more closely match the original ornate companion-card reference.
- Added jewel-like frames, crests, moonlit highlights, rarity-color details and enhanced navigation.
- Improved discovery presentation and responsive layouts.
- Preserved existing game systems, save key, and online update flow.

## v0.6 — Enchanted Interface
- Refined the Home screen around five tall, glowing rarity-framed companion cards.
- Upgraded Seraphine’s card, forest backdrop, top bar, buttons, and sidebar.
- Redesigned Magical Discoveries with a lunar butterfly illustration adapted from the supplied reference artwork.
- Retained existing gathering, expeditions, Awakening, Moonwood restoration, browser saves, and online updater.
- Responsive desktop/mobile styling and reduced-motion support.

## v0.5 — Online Updater
- Added version.json and Update Game screen.

## v0.4 — Meaningful Expeditions
- Branching paths and persistent consequences.


## v0.8 — Seamless Auto Updates
- Checks version.json every 5 seconds while the tab is visible.
- Only reloads when a new published build is detected; saves progress first.
- Defers automatic reload while on the Expeditions screen.
- Manual update button remains available.
