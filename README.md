# Vioverse

Playable gothic fantasy idle gathering and exploration vertical slice.

## Play
Open `index.html` in a browser or publish the repository root via GitHub Pages. Online updates require GitHub Pages.

## v0.9
Home, Expeditions, Discoveries, Legacy, Journal, Patch Notes, and Update Game. Journal includes JSON save export/import. Saves use the existing `moonveil_legacy_v02` browser localStorage key.

To deploy: copy extracted files into your cloned GitHub repository, commit, push to main, and wait for Pages to deploy.
